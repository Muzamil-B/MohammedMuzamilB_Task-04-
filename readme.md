# Task 3 – CSS Units, Box Model & Fonts

## Files
- `index.html` – HTML structure
- `style.css` – External stylesheet

## Features
- 25% spacing from left and right (`25vw`)
- 10% spacing from top and bottom (`10vh`)
- No page scroll (`100vw / 100vh`)
- `box-sizing: border-box` applied globally
- Gradient background button
- Image inside a div
- No flex, no overflow:hidden, no positioning used
